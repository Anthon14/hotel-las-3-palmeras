# Hotel Las 3 Palmeras

Sistema web desarrollado para apoyar la gestión del Hotel Las 3 Palmeras.

El sistema permite administrar habitaciones, clientes, reservas, pagos, comidas, pedidos y usuarios. También cuenta con un apartado para clientes, desde el cual pueden consultar habitaciones, realizar reservas, registrar sus pagos y solicitar comidas.

## Tecnologías utilizadas

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
- Firebase Storage
- XAMPP

## Base de datos

El sistema utiliza una base de datos MySQL llamada `hotel_db`.

Por seguridad, el archivo con la copia de la base de datos no se encuentra incluido en este repositorio.

## Configuración

El archivo `config/conexion.php` contiene los datos privados de conexión a la base de datos y no se incluye en el repositorio.

Como referencia se incluye:

`config/conexion.ejemplo1.php`

Este archivo puede utilizarse como guía para configurar la conexión según el entorno donde se instale el sistema.
